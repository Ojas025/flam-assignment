# A1 — the eval corpus

Part A measurements use FLORES-200: six languages, two splits, parallel by construction.

## Source and size

- Source: [FLORES-200](https://github.com/facebookresearch/flores), fetched with `partA/corpus/download_corpus.py` (SHA-256 verified).
- Parallel means the same sentence appears in every language, in the same order — so cross-language token costs are comparable.

| Split | Sentences per language | Languages | Language-sentence instances |
|---|---|---|---|
| dev | 997 | 6 | 5,982 |
| devtest | 1,012 | 6 | 6,072 |
| **Total** | **2,009** | **6** | **12,054** |

- Languages: English, Hindi, Kannada, Tamil, Telugu, Malayalam.
- **12,054** counts one row per language, not unique sources. Unique sentences = **2,009** (× 6 languages).

## Domain

Dev-split metadata (column `domain`):

- Wikinews — 34.9%
- Wikibooks — 30.2%
- Wikivoyage — 34.9%

Formal written prose (news, how-tos, travel guides). Not chat, slang, or code-mixed text.

## Preprocessing

`partA/corpus/preprocess.py` does only:

- Unicode NFC (one canonical form per character)
- Whitespace cleanup (strip, collapse runs, drop empty lines)
- Alignment check (all six languages must share the same line count)

Casing, wording, and punctuation are left unchanged.

```bash
python partA/corpus/download_corpus.py --corpus flores
python partA/corpus/preprocess.py --corpus flores
```

Output: `partA/corpus/preprocessed_corpus/flores/{dev,devtest}/<lang>.txt`.

## Limits

- Measures written reference text, not casual chat (no code-switching, emoji, abbreviations, or unfinished turns).
- 2,009 sentences per language give a stable average, but not rare cases (URLs, long names, mixed scripts) where token cost spikes.
- Treat these numbers as a fair cross-language comparison under equal meaning — not a production traffic forecast.
